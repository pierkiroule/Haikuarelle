# Carte finale V11

`export-verifie.jpg` est la capture du navigateur de validation. L’image provient du vrai moteur de peinture (rendu 4K V10). La fonction de production `exportSignatureCard` ajoute le titre et les trois vers produits par `artworkPoetry.ts` à partir de ses pixels réels. Le PNG téléchargé mesure 2 304 × 5 110.

`carte-finale.jpg` est une version réduite de ce PNG. Ces fichiers illustrent la vérification ; ils ne sont pas utilisés pour peindre dans l’application. Les pages et fichiers temporaires de validation sont exclus de la publication.
