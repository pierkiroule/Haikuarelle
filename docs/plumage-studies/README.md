# Planches V8

Images issues des vrais shaders de Paint Studio adaptés, calculés avec les
appels GL du moteur TypeScript et les extraits audio embarqués. Aucun rendu
n’a été synthétisé par une IA ou dessiné dans un moteur alternatif.

Les quatre études réutilisent volontairement le même geste d’eau afin de
comparer leurs pigments et leurs marques : graines 95001–95004. La planche
est recadrée et réduite, sans retouche de la matière. Les JPG individuels
conservent le format portrait complet. `detail-4k.jpg` est un recadrage à
l’échelle 1:1 du PNG 2304 × 4096 du pic vert. `rencontre.jpg` montre les
dépôts successifs mésange et bouvreuil, graine de feuille 95011.

Commandes : voir `scripts/render-offscreen.ts` (modes plumages, plumage-pic,
plumage-basis) puis `scripts/replay-egl.py`. Les JSON de validation conservent
les dimensions et les SHA-256 des PNG originaux.
